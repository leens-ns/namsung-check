# 남성초등학교 출결관리 시스템

학교 구성원이 Google 계정으로 출결을 입력·조회하는 웹앱입니다.

- 공식 운영 주소: `https://namsung-check.firebaseapp.com/`
- `index.html`: 운영 화면
- `demo.html`: 실제 서버에 저장하지 않는 체험 화면
- `manual.html`: 로그인 후 역할에 맞게 표시되는 사용 매뉴얼
- `privacy.html`: 코드에 실제 구현된 개인정보 처리 항목과 운영 전 작성이 필요한 학교 정보 초안
- `examples/`: 실제 정보가 아닌 CSV 형식 예시

학생 명단, 학부모 연락처, 출결 기록은 이 저장소에 저장하지 않습니다. 실제 개인정보가 포함된 CSV나 인증서, 비밀키를 저장소에 추가하지 마세요. 운영 권한과 데이터 접근은 Google 로그인 및 Firebase 보안 규칙으로 관리합니다.

운영자는 `privacy.html`의 대괄호 항목에 학교의 법정 명칭, 개인정보 보호책임자, 학생·출결 정보 보유 기준, Firebase·Google·GitHub 등 외부 서비스의 수탁·국외 이전 고지를 실제 계약과 학교 기준에 맞게 보완해야 합니다. 이용자 계정·권한·알림 정보의 보유기간은 관리자 설정에서 계정별 남성초등학교 근무 시작일과 근무 만료일로 관리하며, 만료 후 회원탈퇴 처리는 관리자만 실행합니다.
