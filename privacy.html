메인 화면으로 핵심 안내 처리 항목 보유·파기 이용자 권리

로그인 전 핵심 안내

개인정보 수집 목적 Google 계정으로 이용자를 확인하고, 등록된 권한에 따라 학생 출결 입력·조회와 출결 알림을 제공합니다.
수집하는 개인정보 필수: Google 계정 식별정보와 권한·학급·부서 정보. 학생 출결 업무에 필요한 학생·출결 정보. 선택: 학부모 연락처, 브라우저 알림 토큰.
개인정보 보유기간 이용자 계정·권한·확인 기록·알림 정보는 이용자별 남성초등학교 근무 시작일부터 근무 만료일까지를 기준으로 합니다. 날짜는 관리자가 계정별로 설정합니다.
미동의 시 안내 개인정보 처리 안내를 확인하지 않으면 로그인할 수 없습니다. 브라우저 알림은 선택 사항이며, 허용하지 않아도 출결 입력·조회는 사용할 수 있습니다.

2. 수집·처리하는 개인정보와 목적

구분코드에서 확인된 항목저장 위치 또는 처리 경로처리 목적
Google 로그인 정보 Google 계정 이메일, Firebase Auth UID, 이메일 인증 상태, 표시 이름, 프로필 사진 URL Google 로그인·Firebase Authentication. 표시 이름·사진은 현재 화면 표시용이며 앱이 Firestore에 별도 저장하지 않습니다. UID는 개인정보 안내 확인 기록과 알림 토큰에 저장됩니다. 본인 확인, 등록 계정과의 일치 확인, 화면 표시
이용자 권한·근무기간 이메일, 관리자·교사·방과후강사·외부수업강사 권한, 학년·반, 부서·수업, 담당 학급, 근무 시작일·만료일, 수정자 이메일·수정 시각 Firebase Firestore `access` 컬렉션 권한에 맞는 입력·조회 범위 제공, 근무기간 밖 로그인 차단, 관리자 변경 이력 확인
학생 명단 학생 식별자, 이름, 학년, 반, 번호, 방과후 요일·부서 Firebase Firestore `students` 컬렉션 학생별 출결 입력과 학급·부서별 조회
학부모 연락처 CSV에 입력된 선택적 학부모 연락처 Firebase Firestore `contacts` 컬렉션. 관리자만 읽고 쓸 수 있습니다. 관리자가 필요한 경우 연락처를 확인하기 위한 보조 기능
출결·업무 기록 학생 식별자, 날짜, 학년·반, 방과후 부서, 출결 상태, 특이사항, 수정자 이메일·수정 시각 Firebase Firestore `attendance` 컬렉션 출결 입력, 방과후·외부수업강사 조회, 출결 통계·관리
브라우저 알림 FCM 토큰, Firebase Auth UID, 이메일, 권한, 알림 대상, 강사 언어, 활성 상태, 갱신 시각 브라우저의 Firebase Cloud Messaging 및 Firestore `notificationTokens` 컬렉션. GitHub Actions 자동 알림 작업이 토큰을 읽어 FCM으로 알림을 보냅니다. 앱을 열어 두지 않아도 아침 출결 입력·재확인·방과후 출결 확인·관리자 사용량 확인 알림 제공
기기 내 저장 정보 알림함의 제목·내용·시각·읽음 여부, 언어·사용 모드·외부수업 선택 반, 알림 토큰 동기화 표시, 사용량 안내 닫힘 표시, 로그인 전환 표시 현재 브라우저의 `localStorage` 및 `sessionStorage`. 앱이 서버로 전송하는 저장 항목은 알림 토큰 동기화 정보에 한정됩니다. 기기에서 앱 설정·알림함·로그인 전환 상태 유지

3. 보유기간과 파기

이용자 계정·권한·알림 정보

각 이용자의 계정·권한·근무기간·개인정보 처리 안내 확인 기록·등록 알림 토큰은 남성초등학교 근무 시작일부터 해당 이용자의 근무 만료일까지를 보유기간 기준으로 합니다. 시작일과 만료일은 관리자 화면에서 계정별로 입력합니다.

근무 시작일 전이나 만료일 후에는 시스템 로그인이 차단됩니다. 만료 후 관리자는 관리자 설정 → 회원탈퇴 처리를 실행해 해당 계정의 시스템 접근 권한, 개인정보 안내 확인 기록, 등록된 알림 토큰을 삭제합니다.

관리자 회원탈퇴 처리는 Google 계정·Firebase Authentication 사용자 자체와 학생·출결 기록을 삭제하지 않습니다. 학생·출결 기록의 보유기간은 학교의 별도 보관 기준을 정해 이 문서의 빈칸을 보완해야 합니다.

학생·출결 정보

현재 코드에는 학생·학부모 연락처·출결 정보의 학교별 최종 보유기간이 고정되어 있지 않습니다. 학교 기준을 다음과 같이 확정해 입력해야 합니다: [학생 명단·학부모 연락처·출결 기록의 보유기간을 입력하세요]

관리자가 무료 운영·자료 보관 설정에서 자동 삭제를 켜면 GitHub Actions가 설정한 12·24·36·60개월 기준보다 오래된 출결 기록만 월 1회 삭제합니다. 기본 설정은 자동 삭제 꺼짐이며 학생 명단과 연락처는 이 작업으로 삭제하지 않습니다.

파기 절차와 방법

  • 관리자 회원탈퇴: `access`, `privacyAcknowledgements`, 해당 계정의 `notificationTokens` 문서를 Firebase Firestore에서 삭제합니다.
  • 학생 명단 CSV 전체 교체·전체 삭제: `students`와 관리자 전용 `contacts`에서 대상 문서를 삭제합니다. 출결 기록은 유지됩니다.
  • 담임교사의 학생 개별 삭제: 현재 보안 규칙상 `students`만 삭제하며 학부모 연락처는 관리자 전용 보호를 위해 남을 수 있습니다. 관리자가 연락처를 별도로 정리해야 합니다.
  • 브라우저에 남은 알림함·언어·사용 모드 정보는 관리자 회원탈퇴로 지워지지 않습니다. 해당 기기의 브라우저 사이트 데이터 삭제로 정리할 수 있습니다.

Firebase Firestore·Firebase Hosting 권한, 학생, 연락처, 출결, 설정, 알림 관련 문서 저장 및 웹앱 제공 [Firebase 수탁자 정보, 서버 지역, 국외 이전 고지와 계약 내용을 입력하세요]
Firebase Cloud Messaging 등록된 브라우저 FCM 토큰으로 출결 관련 알림 전송 [FCM 수탁자 정보와 국외 이전 내용을 입력하세요]

현재 코드에서 결제, 광고·통계 분석 도구, AI 호출, 위치·카메라·마이크 수집은 확인되지 않았습니다. 브라우저 권한 정책에서도 위치·카메라·마이크를 허용하지 않습니다.

5. 이용자의 권리와 행사 방법

이용자는 자신의 개인정보에 대해 열람, 정정, 삭제, 처리정지 등을 요청할 수 있습니다. 요청 방법과 담당자는 다음 빈칸을 학교가 채워야 합니다.

  • 요청 접수처: [담당 부서·이메일·전화번호를 입력하세요]
  • 본인 확인 방법: [학교가 정한 본인 확인 방법을 입력하세요]
  • 처리 기한 및 이의 제기 방법: [학교 기준을 입력하세요]

시스템 안에서는 이용자 본인이 회원탈퇴를 실행할 수 없으며, 업무상 관리자만 관리자 설정에서 계정 이용 해제를 실행합니다. Google 계정 자체 삭제는 Google 계정 설정에서 별도로 진행해야 합니다.

6. 자동 수집 장치와 거부 방법

  • 앱 코드에서 웹 쿠키를 직접 설정하거나 읽는 처리는 확인되지 않았습니다.
  • 로그인 전환, 사용 모드, 언어, 알림함, 외부수업 선택 반 등은 브라우저 저장공간에 기록됩니다. 브라우저의 사이트 데이터 삭제 기능으로 삭제할 수 있습니다.
  • 브라우저 알림은 선택 기능입니다. 알림을 원하지 않으면 앱의 이 기기 알림 등록 해제를 누르거나 브라우저 사이트 설정에서 알림을 차단하세요. 알림을 거부해도 출결 입력·조회는 가능합니다.
  • Google·Firebase·GitHub 등 외부 서비스가 자체적으로 처리하는 접속 로그·기술 정보는 각 서비스의 정책이 적용될 수 있습니다. 이 앱 코드에서 해당 로그의 항목을 직접 확인할 수 없으므로 여기서 구체적으로 확정하지 않았습니다.

7. 보안 및 공개 저장소 안내

학생 명단·학부모 연락처·출결 기록은 GitHub 저장소에 포함하지 않습니다. 공개 저장소에는 코드와 실제 정보가 아닌 예시 CSV만 게시하며, 실제 데이터 접근은 Google 로그인과 Firebase Firestore 보안 규칙으로 제한합니다.

공개 저장소의 코드가 보인다는 사실과 Firebase 데이터가 공개된다는 사실은 별개입니다. 다만 실제 CSV·토큰·비밀키를 저장소나 메시지에 올리지 않는 운영 원칙을 지켜야 합니다.
